# 🏥 BILIK GERAKAN - Health Intelligence Dashboard

A comprehensive healthcare dashboard built with HTML5, Chart.js, and Leaflet Maps.

## 🎯 Features

- ✅ 4 Real-time KPI Cards
- ✅ 3 Interactive Charts (Diagnosis, Gender, Age Group)
- ✅ Interactive Leaflet Map with geographic distribution
- ✅ 5 Recent records sidebar
- ✅ Master data table with pagination (10 rows per page)
- ✅ Advanced cross-filtering capabilities
- ✅ Responsive design (Mobile, Tablet, Desktop)
- ✅ Malay (Bahasa Melayu) language support
- ✅ Professional UI/UX with smooth animations

## 📊 Data

- 250 randomly generated healthcare records
- Includes: Name, Diagnosis, Gender, Age, Location, Week, Status, Severity, Temperature
- Real-time data generation on page load

## 🔗 Live Demo

Visit: `https://YOUR_USERNAME.github.io/bilik-gerakan`

## 🏗️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Charts**: Chart.js with Data Labels plugin
- **Maps**: Leaflet.js with OpenStreetMap
- **Styling**: Custom CSS with Gradient themes

## 🎨 Customization

Edit `index.html` to:
- Change colors (line ~40-46)
- Modify chart types
- Update healthcare data
- Add new filters

## 📱 Responsive Breakpoints

- Desktop: 1024px+
- Tablet: 768px - 1024px
- Mobile: < 768px

## 👨‍💻 Development

Simply edit `index.html` and push to GitHub. Changes deploy automatically!
